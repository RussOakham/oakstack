# Principle: Consumer owns ledger rows

**When it applies:** Mistake ledgers, process traps in kickoffs, friction promote.

**Rule:** Oakstack owns the **need + process + schema/tools** for a ledger. Each consuming project owns its **trap rows**. The kit never becomes the shared trap dump.

**Stop when:** Someone proposes merging Homestead (or any consumer) live rows into Oakstack `main` — keep example rows only.

**Cite in kickoffs as:** `consumer-owns-ledger-rows`
