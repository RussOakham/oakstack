# Principle: Tracker SoT, not chat

**When it applies:** Specs, tickets, acceptance criteria, and triage state.

**Rule:** The **issue tracker** is the source of truth. Chat and the project store hold drafts and receipts only.

**Stop when:** A “decision” exists only in a chat paste or store note with no tracker link — publish or link before implement.

**Cite in kickoffs as:** `tracker-sot-not-chat`
